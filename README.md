# Django Store 🛒

متجر إلكتروني كامل مبني بـ Django، يدعم الدفع عبر **Stripe** و **PayPal**، مع سلة تسوق، إدارة الطلبات، وإرسال بريد إلكتروني للتأكيد.

A full-featured e-commerce store built with Django, supporting **Stripe** and **PayPal** payments, cart management, order handling, and email confirmation.

---

## ✨ المميزات | Features

### المتجر
- 🏠 **الصفحة الرئيسية** مع عرض المنتجات المميزة والسلايدر
- 🗂️ **التصنيفات** مع ترقيم الصفحات (Pagination)
- 🔍 **البحث** عن المنتجات بالاسم
- 📄 **صفحة تفاصيل المنتج** مع وصف كامل ومعلومات المؤلف

### السلة
- 🛒 **سلة تسوق** مبنية على الجلسات (Sessions)
- ➕ **إضافة / إزالة** المنتجات عبر AJAX
- 💾 **حفظ السلة** في قاعدة البيانات

### الدفع
- 💳 **Stripe** - الدفع ببطاقة الائتمان
- 💰 **PayPal** - الدفع بحساب PayPal
- 📧 **إرسال بريد إلكتروني** لتأكيد الطلب (HTML Email)
- 🧾 **إنشاء فاتورة** برقم الطلب والمنتجات

### لوحة التحكم
- 🔧 **Django Admin** لإدارة المنتجات، الطلبات، والمعاملات
- 👁️ **عرض تفاصيل الطلب** مع المنتجات في صفحة مخصصة

### أخرى
- 🌍 **دعم تعدد اللغات** (i18n) - العربية والإنجليزية
- 🎨 **تصميم متجاوب** مع Bootstrap 5
- 🔒 **متغيرات البيئة** (.env) لحماية المفاتيح
